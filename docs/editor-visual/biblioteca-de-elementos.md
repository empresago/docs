# Biblioteca de elementos

A **Biblioteca** guarda cópias de elementos (um botão, um bloco de texto, um cartão) para você reutilizar. Copie um elemento para a Biblioteca e insira-o em outro ponto da página, antes ou depois de qualquer elemento.

## Copiar um elemento para a Biblioteca

Há duas formas.

### Pelo menu do elemento

1. [Selecione o elemento](./selecionar-elementos) e abra o menu do elemento (⋯).
2. Clique em **Salvar na biblioteca**.

   ![Item Salvar na biblioteca no menu do elemento](/img/editor-visual/biblioteca-de-elementos/01-salvar-na-biblioteca.png)

3. O editor confirma com o aviso **Elemento copiado para a biblioteca**.

   ![Aviso de elemento copiado](/img/editor-visual/biblioteca-de-elementos/02-copiado.png)

### Pelo botão Biblioteca

Com o elemento selecionado, clique em **Biblioteca** na barra do editor e escolha **Copiar para Biblioteca**.

![Menu do botão Biblioteca](/img/editor-visual/biblioteca-de-elementos/03-menu-biblioteca.png)

1. **Biblioteca**: abre o menu.
2. **Abrir Biblioteca**: abre a lista de elementos guardados.
3. **Copiar para Biblioteca**: copia o elemento selecionado.

## Ver os elementos guardados

Clique em **Biblioteca** e em **Abrir Biblioteca**. A lista abre na lateral esquerda, com uma prévia de cada elemento.

![Gaveta da Biblioteca de elementos](/img/editor-visual/biblioteca-de-elementos/04-gaveta.png)

1. A **prévia** do elemento guardado e, abaixo dela, o nome (a etiqueta e o começo do texto).
2. As ações do elemento: o **lápis** (**Renomear**), a **lixeira** (**Excluir**) e as **reticências (⋮)**, que abrem as opções de inserção.

Use **Atualizar** para recarregar a lista e o **X** para fechar.

## Inserir um elemento da Biblioteca na página

1. Na página, **selecione o elemento de referência**: o novo elemento será colocado antes ou depois dele.
2. Abra a Biblioteca, como acima.
3. Na linha do elemento que você quer inserir, clique nas **reticências (⋮)**.

   ![Opções Inserir antes e Inserir depois](/img/editor-visual/biblioteca-de-elementos/05-menu-do-item.png)

   1. Botão com as opções do elemento.
   2. **Inserir antes**: coloca o elemento logo antes do selecionado.
   3. **Inserir depois**: coloca o elemento logo depois do selecionado.

4. Clique na opção desejada. O editor avisa **Elemento inserido** e a cópia aparece na página.

   ![Elemento inserido depois do elemento selecionado](/img/editor-visual/biblioteca-de-elementos/06-inserido.png)

   1. O elemento de referência (o que estava selecionado).
   2. O elemento inserido, logo depois dele.
   3. O aviso **Elemento inserido**.

O elemento inserido é como qualquer outro da variante: você pode [editar o texto](./editar-texto), mudar os [estilos](./estilos) e desfazer com **Desfazer**.

## Inserir pelo menu do elemento

Também dá para começar pelo elemento: selecione-o, abra o menu do elemento (⋯) e clique em **Inserir novo bloco**. O editor pergunta **Onde inserir o novo bloco?**, com as opções **Antes do elemento** e **Depois do elemento**.

![Pergunta sobre onde inserir o novo bloco](/img/editor-visual/biblioteca-de-elementos/07-novo-bloco-bruto.png)

## Excluir da Biblioteca

Na lista, clique na **lixeira** do elemento. Ele sai da lista na hora e o editor avisa **Elemento excluído**. A exclusão vale para a Biblioteca da conta e continua valendo ao reabrir a lista com **Atualizar**.

Isso remove apenas a cópia guardada: a página e as variantes não mudam. Se o painel não conseguir excluir, o editor avisa **Erro ao excluir elemento** e a lista volta a mostrar o elemento.

**Variante (depois):**

![Variante com o elemento da Biblioteca inserido](/img/editor-visual/biblioteca-de-elementos/resultado-depois.png)
