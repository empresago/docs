# GoAB Survey SDK iOS

Documentação do **Survey SDK para iOS** em preparação.

## Em breve

A integração de pesquisas in-app no iOS seguirá o mesmo modelo do [Survey SDK Android](../android-survey/intro):

- ativação por eventos na app
- apresentação automática de surveys
- contexto de utilizador e telemetria integrada

Enquanto isso, consulte o guia Android:

- [Início rápido (Android)](../android-survey/getting-started)
- [API Reference (Android)](../android-survey/api-reference)
